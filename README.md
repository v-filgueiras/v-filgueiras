### 👨‍💻 Sobre mim

Desenvolvedor backend com foco em **Java e Spring Boot**, atuando na construção de **APIs REST escaláveis**, seguras e orientadas a boas práticas de arquitetura.

Tenho experiência no desenvolvimento de aplicações com **arquitetura em camadas**, integração com **bancos de dados relacionais** e implementação de soluções utilizando **microsserviços e mensageria**.

Aplico conceitos como **Clean Code, SOLID e boas práticas de engenharia de software**, garantindo código legível, testável e de fácil manutenção.

Também possuo experiência com **containerização utilizando Docker**, **testes automatizados (JUnit e Mockito)** e integração de sistemas com **Apache Kafka**, buscando sempre construir aplicações resilientes e preparadas para ambientes de produção.
